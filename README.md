## AnimatedYASB

An animation-focused fork of [YASB](https://github.com/amnweb/yasb), exploring smoother UI transitions and animated menus.

## 🎥 Video

https://github.com/user-attachments/assets/5b0cb96a-5a61-42a4-9375-5a079bf58f7c

## ⚠️ Experimental

AnimatedYASB is a personal fork and experimental project. It is intended to demonstrate and explore animation work within the YASB codebase and may contain bugs or break existing functionality.

Please back up your YASB configuration before using it.

## ✨ Animated Components

Animations have been added to:

- Home Menu
- Windows Desktop Context Menu
- Windows Desktop Rename Menu
- Bar Context Menu
- Clock Menu
- Clock Context Menu
- Media Menu
- Wi-Fi Menu
- Volume Menu
- Battery `alt_label`
- System Tray Context Menu
- Power Menu
